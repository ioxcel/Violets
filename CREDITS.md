## Public services used at runtime

Some tools query public endpoints. Only the lookup term you enter is sent. No
account, credential or personal detail is transmitted.

- IP / Domain Lookup: ip-api.com
- Subdomain Finder: crt.sh
- DNS Records: dns.google
- Wayback Machine: archive.org
- Pwned Password: api.pwnedpasswords.com
- Geolocator and Photo Geotag: nominatim.openstreetmap.org
- MAC Vendor: api.macvendors.com
- BIN Lookup: lookup.binlist.net
- Discord tools: the public Discord API

Each service is subject to its own terms of use.
